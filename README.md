# DJ Soheil Website — soheilsadeghi.com

وب‌سایت دوزبانه (فارسی / English) DJ Soheil با پنل مدیریت کامل: دوره‌های DJing و Ableton Live، راهنمای خرید، بیوگرافی، بخش دانلود، پنل هنرجو، جستجو و دستیار هوشمند عیب‌یابی.

Next.js 16 · Payload CMS 3 (پنل مدیریت) · SQLite · Tailwind CSS v4 · GSAP · Lenis

## اجرا روی سیستم خودتان

```bash
npm install
npm run dev        # http://localhost:3000  — پنل: http://localhost:3000/admin
```

اولین بار که `/admin` را باز کنید، فرم ساخت **حساب مدیر** نمایش داده می‌شود. اولین حساب همیشه مدیر کل است.

## انتشار روی هاست

سایت روی سرور Ubuntu اجرا می‌شود؛ ساختار سرور، به‌روزرسانی (`sudo soheil-update`)، ایمیل، وب‌میل (`mail.soheilsadeghi.com`) و پشتیبان‌گیری: **[DEPLOY.md](DEPLOY.md)**. راهنمای جایگزین برای هاست cPanel: [DEPLOY-CPANEL.md](DEPLOY-CPANEL.md).

## پنل مدیریت (`/admin`)

همه متن‌ها و بخش‌های سایت از پنل ویرایش می‌شوند. هر صفحه برای **فارسی** و **انگلیسی** جداگانه پر می‌شود؛ زبان محتوا را از بالای هر صفحه انتخاب کنید.

| بخش پنل | کاربرد |
| --- | --- |
| **محتوای صفحات** | صفحه اصلی، دوره DJing، دوره Ableton، راهنمای خرید، بیوگرافی، صفحه تماس |
| **تنظیمات سایت** | نام، عکس، شبکه‌های اجتماعی، باکس دعوت، **منوی سایت**، **دستیار چت و پایگاه دانش** |
| **دانلود و آموزش** | آیتم‌های دانلود (مشاپ، پادکست، ترک، نرم‌افزار، پلاگین)، محتوای دوره‌ها، فایل‌های خصوصی |
| **محتوا** | برگه‌های دلخواه (با آدرس `/نامک`)، کتابخانه رسانه |
| **کاربران و گروه‌ها** | هنرجوها، مدیران، ویرایشگرها و گروه‌های کلاس |
| **درخواست‌ها** | درخواست‌های فرم تماس و رزرو |
| **پشتیبان‌گیری** | دکمه دانلود بکاپ کامل و بکاپ دیتابیس به‌صورت zip (فقط مدیر کل) در داشبورد |

امکانات: پیش‌نویس و انتشار، تاریخچه نسخه‌ها و بازگردانی، پیش‌نمایش، ویرایشگر متن غنی، پنل فارسی و راست‌چین.

اطلاع‌رسانی ثبت‌نام هنرجو و درخواست تماس از سه راه: ایمیل، پیامک (sms.ir) و تلگرام — هرکدام که تنظیم شده باشد. تنظیمات در [.env.example](.env.example) و [DEPLOY.md](DEPLOY.md).

### نقش‌ها و دسترسی

- **مدیر کل:** همه‌چیز، از جمله تعیین نقش کاربران.
- **ویرایشگر:** همه محتوا، بدون مدیریت نقش‌ها.
- **هنرجو:** با ثبت‌نام در سایت ساخته می‌شود. محتوای **گروه‌هایی** را می‌بیند که مدیر او را عضوشان کرده است.

هنرجو بعد از ثبت‌نام ایمیلش را با لینکی که برایش ارسال می‌شود تأیید می‌کند. این مرحله فقط وقتی فعال است که ایمیل سایت روشن باشد؛ راهنما در بخش «ایمیل سایت» در [DEPLOY.md](DEPLOY.md). زبان پنل مدیریت با دکمه فارسی / English در بالای پنل عوض می‌شود.

### دسترسی دانلودها

برای هر آیتم دانلود یکی را انتخاب کنید:

- **همه بازدیدکنندگان**
- **فقط کاربران واردشده:** در لیست با قفل نمایش داده می‌شود.
- **فقط گروه‌های انتخابی:** برای بقیه کاملاً پنهان است.

فایل‌ها هیچ‌وقت آدرس مستقیم عمومی ندارند و فقط از مسیر محافظت‌شده ارائه می‌شوند. برای فایل‌های خیلی حجیم از «لینک خارجی» استفاده کنید.

## ساختار

```
src/
  app/(frontend)/[locale]/   صفحات سایت (fa در ریشه، en زیر /en)
  app/(payload)/             پنل مدیریت و REST API
  app/api/                   چت، فرم تماس، جستجو، دانلود محافظت‌شده
  payload/                   تعریف بخش‌های پنل (collections / globals)، دسترسی‌ها، داده اولیه
  payload.config.ts          تنظیمات Payload
  i18n/                      زبان‌ها و متن‌های ثابت رابط کاربری
  content/site.ts            محتوای اولیه فارسی (فقط برای اولین اجرا)
  migrations/                ساختار پایگاه داده
```

## دستورات

| دستور | کاربرد |
| --- | --- |
| `npm run dev` | اجرای محلی (اول migrationها را اجرا می‌کند) |
| `npm run build` | بیلد نهایی |
| `npm run package:cpanel` | بیلد + ساخت zip آماده آپلود در `deploy/` |
| `npm run typecheck` | بررسی TypeScript |
| `npm run generate:types` | ساخت دوباره `payload-types.ts` بعد از تغییر ساختار پنل |
| `npm run migrate:create -- name` | ساخت migration بعد از تغییر ساختار پنل (برای توسعه‌دهنده) |

متغیرهای محیطی (آدرس سایت، رمز امنیتی، ایمیل، هوش مصنوعی، تلگرام): **[.env.example](.env.example)**
